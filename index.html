Algebra is a branch of mathematics that uses symbols (usually letters) to represent unknown values. It helps us solve problems and describe patterns.

🔢 Key Rule 1: Variables & Expressions

A variable is a letter that stands for an unknown number (like x, y, n). An algebraic expression combines numbers, variables, and operations.

📌 Example: 3x + 5 means "3 times a number, plus 5"

⚖️ Key Rule 2: Solving Linear Equations

To solve an equation, do the same operation on both sides to isolate the variable.

📌 Example: 2x + 3 = 11
Subtract 3: 2x = 8 → Divide by 2: x = 4

📐 Key Rule 3: Order of Operations (PEMDAS)

Parentheses → Exponents → Multiplication/Division → Addition/Subtraction

📌 Example: 2 × (3 + 4)² = 2 × 49 = 98

📝 Key Rule 4: Word Problems to Equations

Translate words into math: "sum" = + , "difference" = – , "product" = × , "quotient" = ÷ .

📖 Example Word Problem: "Five less than twice a number is 11. Find the number."
→ Let n be the number: 2n - 5 = 11 → 2n = 16 → n = 8

🧩 Key Rule 5: Distributive Property

Multiply each term inside parentheses: a(b + c) = ab + ac

📌 Example: 3(x + 4) = 3x + 12

📊 Key Rule 6: Combining Like Terms

Add or subtract terms that have the same variable.

📌 Example: 4x + 2y - x + 3y = 3x + 5y

🧠 Practice Word Problem (Solved with Algebra)

Problem: A rectangle has length 3 cm more than twice its width. The perimeter is 36 cm. Find the width and length.

Solution:
Let w = width. Then length L = 2w + 3.
Perimeter = 2(L + w) = 2( (2w+3) + w ) = 2(3w+3) = 6w + 6 = 36
6w = 30 → w = 5 cm, L = 2(5)+3 = 13 cm.
